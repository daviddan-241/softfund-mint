# Softfund NFT Minter

This is a fully static NFT minting page for the Softfund collection.

## Features
- Connect Phantom or Trust Wallet
- Mint NFTs with direct SOL payment to the treasury wallet
- Unique metadata per NFT from Lighthouse/IPFS
- Configurable number of NFTs and price

## How to Deploy
1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com/), click "New Project".
3. Import this repo, choose **Other / Static** framework preset.
4. Deploy.
5. Visit your deployed URL and start minting.

## Notes
- Replace placeholder CIDs in `index.html` with your real metadata CIDs.
- Price is currently set at `$2.672` per NFT.
- Max supply is 10,000 NFTs.# softfund-mint
